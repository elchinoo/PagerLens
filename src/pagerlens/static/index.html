Connect an AI assistant

PagerLens exposes incidents, hypotheses and runbooks as an MCP server, so tools like Claude Code, VS Code or Codex can ask "why is checkout failing?".

  1. Create a read-only API token under Settings, then API tokens. (Use a full token only if the assistant should run investigations and mark root causes.) Put it in the environment where the client runs: 
    export PAGERLENS_TOKEN=<your token>
  2. Pick your client and apply the configuration:

  3. Ask your assistant: "Using pagerlens, what incidents are open and what is the most likely cause of the newest one?"
