## 7 am_eric
PagerLens has two more investigation methods, and both use a language model.

The first is AI. A model drives the same read-only tools.

The second is Rules plus AI. It runs both, and reconciles them.

When they agree, confidence goes up.

When only the model believes something, its confidence is capped.

And anything the model claims is checked against real evidence.

The model has no tool that changes anything.

To use a model, you add a provider account in settings.

Keys are stored encrypted, and never shown again.

One warning. Log excerpts do leave your server for these methods. So choose your provider with care.

We have not measured accuracy on live models yet.
